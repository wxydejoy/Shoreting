    连接安卓

    下面三项就是安卓「岸亭 → 设置」里要填的地址 / 端口 / Token。手机和这台机器要在同一局域网。

    安卓里填 … 17890 名称显示为 study
    安卓端怎么填？连不上怎么排查？
    1. 装 APK：从 GitHub Release 下载（旧包名可能还是 Helm-*.apk），允许「安装未知应用」。
    2. 打开岸亭（横屏全屏）。没连上 Hub 前是预览模式，数据是假的。
    3. 点主屏顶部 PC 监控条（CPU / 内存那一行）进入设置。
    4. 依次填：地址 = …，端口 = 17890，Token = 上面复制的那个。
    5. 点 测试连接，成功会提示「已连接」。
    连不上排查
    • 运行 Hub 的那台机器（Mac 或 Windows）上，岸亭 Hub 进程是否在跑
    • 手机和它是否同一网段（别一个 Wi‑Fi 一个有线不同段）
    • 运行 Hub 的机器防火墙要放行 TCP 17890
    • Token 是否完全一致（重新生成后安卓也要改）

    电脑监控

    不需要额外软件就能显示 CPU / 内存占用；有 NVIDIA 显卡还会显示 GPU。要显示 CPU 温度看下面的说明。

    CPU 温度：为什么读不到？怎么修？

    PawnIO 是 Windows 上的小驱动，让普通程序能读到 CPU 温度传感器。 不装也不影响开关灯、启动程序，只是主屏上没有温度数字。

    两个前提：① 装 PawnIO；② 岸亭 Hub 以管理员身份运行（右键 exe → 以管理员身份运行，或用 run-admin.ps1）。

    1. 右键「终端 / PowerShell」→ 以管理员身份运行
    2. 执行：
      winget install -e --id namazso.PawnIO
    3. 没有 winget：从 GitHub Release 或 pawnio.eu 下载安装
    4. 装完退出 Hub，再以管理员身份启动
    5. 看主屏温度是否出现；不行就查日志 %USERPROFILE%\\.config\\dock-hub\\hub.log

    安卓端还有这些设置

    都在岸亭的设置页（同样是点主屏顶部 PC 监控条进入）：

    • 视频背景：选本地横屏视频，循环静音播放
    • 方块样式 / 字体 / 字号：调整主屏外观
    • 插电亮屏 / 拔电熄屏：需要授予设备管理员（只用于锁屏）
    • 电脑关机后熄屏：以 Windows 探针的在线状态为准
    • 媒体控制：需要在系统里开启岸亭的通知使用权
