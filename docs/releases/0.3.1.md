## Helm v0.3.1

- **Helm-0.3.1.apk** — 安卓客户端（红米 K20，versionCode 4）

Hub 仍用 [v0.3.0](https://github.com/wxydejoy/Helm/releases/tag/v0.3.0) 的 `DockHub-0.3.0.exe`。

### 插电亮屏 / Hub 断连熄屏
- 开启「插电亮屏、拔电熄屏」后：Hub **长时间连不上**会压黑屏幕（应用仍在后台跑），Hub 恢复后**自动亮屏**
- 设置页新增 **Hub 断连后熄屏**（30 秒 / 1 分钟 / 2 分钟 / 5 分钟）
- 设置页新增 **定时探测间隔**（10 / 15 / 30 / 60 秒），后台探测 Hub 是否恢复
