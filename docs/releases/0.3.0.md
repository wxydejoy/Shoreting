## Helm v0.3.0

- **Helm-0.3.0.apk** — 安卓客户端（红米 K20）
- **DockHub-0.3.0.exe** — Windows Hub（配置向导、页内米家扫码、自动保存）

### 安卓（Helm-0.3.0.apk）
- 主屏编排：长按进入编辑，拖动移动、右下角缩放
- 模块可隐藏或去底；设置 → 主屏布局可单独开关显示与背景
- 坐标按比例保存，换屏比例不易错位

### Windows（DockHub-0.3.0.exe）
- 托盘：**打开配置向导** / **退出**（首次启动自动打开向导）
- 向导 `http://127.0.0.1:17890/setup`（仅本机）：复制 IP/端口/Token、页内米家扫码、设备列表、自动保存
- CPU 温度需 **以管理员身份运行** + 可选安装 PawnIO

### 使用
1. Windows：右键 **以管理员身份运行** `DockHub-0.3.0.exe`，在向导里完成米家登录与设备配置
2. 安卓：安装 APK，点顶部 PC 监控条进设置，填向导里的地址 / 端口 `17890` / Token，测试连接
